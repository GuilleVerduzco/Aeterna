      Lo que dice el diagrama sobre cómo está montado hoy.

      1. Una sola fuente viva. El tablero lee solo la base compartida del artefacto. Supabase y Meta están listos, pero pausados. Sin Meta, las cifras de Instagram siguen siendo manuales.
      2. Un punto único de falla en la publicación. Instagram y Facebook salen por Composio, y WhatsApp por Kapso. Los registros del Agente Manager y del Reporte diario marcan error desde el 17 oct, aunque los posts sí aparecen. El problema está en el registro o en los permisos de la sesión automática, y hay que revisarlo.
      3. Vercel está conectado pero sin uso. El tablero no está desplegado en un dominio propio. Conviene desplegarlo cuando haya datos de Meta, porque Supabase ya tiene el esquema.

      Cómo se actualiza: el tablero local (~/.claude/tablero/tablero-local.html) se regenera cada vez que abres Claude Code. Para actualizar este enlace, dile a Claude «actualiza el tablero».

      Qué incluye: solo Claude Code en esta computadora. Los chats de claude.ai y Cowork no aparecen en tokens ni en valor API, pero sí cuentan en los porcentajes del plan.

      Cómo se calcula: tokens tomados de las transcripciones, sin duplicados. El valor API usa las tarifas de config.json: caché leída al 10 % y caché guardada al 125 % (5 min) o al 200 % (1 h). Si Claude Code registró el costo de una sesión, se ajusta a esa cifra, porque las transcripciones no guardan todas las llamadas. «Tokens por respuesta» de cada extensión ≈ caracteres que agrega al contexto ÷ 4. Estados: Mantener = 3 o más usos en la ventana; Quitar = sin usos y visto hace más de 7 días; Evaluar = el resto.
